核心開發過程指南
================

本文件的目的是幫助開發人員（及其經理）以最少的挫折與開發社群合作。它試圖以
一種讓不熟悉 Linux 核心開發（或者說，一般的自由軟體開發）的人也能理解的方式，
記錄這個社群的運作方式。雖然這裡有一些技術內容，但這基本上是一份以流程為主的
討論，不需要對核心程式設計有深入了解也能讀懂。
